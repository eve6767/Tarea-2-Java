# Sistema de Gestión de Reuniones

Este proyecto implementa un sistema orientado a objetos para la gestión de reuniones, registrando participantes, asistencias, retrasos, notas y generación de informes. Las reuniones pueden ser presenciales o virtuales.

## Funcionalidad general

La implementación cumple con los siguientes objetivos:
- Crear reuniones con fecha, hora y duración prevista.
- Invitar personas individualmente o departamentos completos.
- Registrar asistencia y notas durante la reunión.
- Calcular porcentaje de participacion.
- Generar un informe .txt la información de la reunión.
